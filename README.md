# 🚀 Python to Machine Learning Foundations

Welcome to my learning repository! This project tracks my personal curriculum, code notebooks, and
progress as I transition from core Python programming into the foundations of Machine Learning. 

The primary goal of this repository is to build a rock-solid mathematical and practical understanding of ML algorithms 
from the ground up.

---

## 📈 Learning Roadmap & Progress

### 🟩 Phase 1: Core Python Foundations
*   [x] Variables, Data Types, and Control Flow
*   [x] Data Structures (Lists, Dictionaries, Sets, Tuples)
*   [x] Functions, Scope, and Functional Programming Modules
*   [x] Object-Oriented Programming (OOP) in Python
*   [ ] File Handling and Exception Management

### 🟨 Phase 2: The Data Science Stack
*   [ ] **NumPy:** Multi-dimensional arrays, vectorization, and linear algebra fundamentals
*   [ ] **Pandas:** DataFrames, data cleaning, manipulation, and preprocessing
*   [ ] **Matplotlib & Seaborn:** Data visualization, statistical plotting, and exploratory data analysis (EDA)

### 🟦 Phase 3: Mathematical Foundations for ML
*   [ ] **Linear Algebra:** Matrices, vectors, eigenvalues, and eigenvectors
*   [ ] **Calculus:** Derivatives, partial derivatives, and Gradient Descent math
*   [ ] **Probability & Statistics:** Descriptive stats, distributions, and hypothesis testing

### 🟧 Phase 4: Machine Learning Foundations
*   [ ] **Supervised Learning:** Linear Regression, Logistic Regression, Decision Trees
*   [ ] **Unsupervised Learning:** K-Means Clustering, PCA (Dimensionality Reduction)
*   [ ] **Model Evaluation:** Cross-validation, Bias-Variance tradeoff, Overfitting, Metrics (Precision, Recall, F1, ROC-AUC)
